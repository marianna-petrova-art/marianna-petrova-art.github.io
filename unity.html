Unity Project

Unity, 3D Game Development, AI-Assisted C#

This is a small learning project I developed over approximately one month to explore 3D game development in Unity.

I used free 3D assets to build a small environment and focused on making it interactive. As I worked on the project, I learned to use the Unity editor, set up interactions, and test gameplay mechanics.

What I Worked On

I created a small interactive 3D environment in Unity using free assets. My main focus was learning to use the Unity editor and implement gameplay mechanics.

I used ChatGPT to generate C# scripts based on the mechanics I wanted to create. I added the scripts to Unity, tested them, identified problems, and requested changes until the interactions worked as intended.

During this project, I worked on:

  • Building the environment and adjusting lighting
  • First-person movement and camera controls
  • Picking up, carrying, and dropping objects
  • Opening doors, drawers, windows, and the refrigerator
  • Combining ingredients to prepare a sandwich
  • Adding timed interactions, such as washing hands and eating
  • Creating interaction prompts, progress bars, and character thoughts
  • Using conditions to control when certain actions are available

My Learning Experience

This project helped me become more confident using the Unity editor, setting up objects and components, and troubleshooting gameplay interactions. I learned how to describe the behaviour I wanted, test AI-generated scripts, and refine the results through repeated iterations.

I'm continuing to learn Unity and enjoy experimenting with new gameplay mechanics.
